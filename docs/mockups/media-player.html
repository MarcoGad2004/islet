Notes
  • Pill text. Wi-Fi shows the network name, Bluetooth the connected device, AirDrop Contacts or Everyone, Mirroring the display it is connected to, and battery stays the percentage. With nothing connected a pill falls back to its own name. Names get the space they need and are cut with an ellipsis; the battery never shrinks.
  • Controls needing checks before code: shuffle, repeat, like and skip by 15 s use other media commands than the three Islet sends today. I'd test each against Music, Spotify and a browser tab. A player that doesn't support one gets that button dimmed, and Like is the likeliest to be missing (I'd hide it where it can't work).
  • State: shuffle, repeat and like should reflect the player's real state (green when on, as drawn). That needs the player to report it, which isn't read today either.
  • The pills are status only: a tap opens the control's page (Battery, Wi-Fi, Bluetooth), and toggling stays on the Controls page. Tell me if you'd rather a tap toggled.
